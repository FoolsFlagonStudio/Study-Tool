# Problem Types

Generator specs per topic: the question template, the answer format, and the common mistakes used as multiple-choice distractors. One table per module.

## Module 1: Polynomials and Exponents
Notes for building generators in the study tool. Each row is a problem template; "distractors" are the wrong-answer patterns to use for multiple choice.

| Topic | Template | Answer format | Distractors (common mistakes) |
|---|---|---|---|
| polynomial-basics | Is this expression a polynomial? | yes / no + reason | negative or fractional exponent, variable in denominator |
| classifying-polynomials | Name $p(x)$ (sometimes unsimplified) | "[degree] [terms]" | count terms before simplifying; wrong degree name |
| combining-like-terms | Simplify a 5-7 term expression | polynomial | add exponents when combining; combine unlike terms |
| laws-of-exponents | Simplify a product/quotient/power of monomials | monomial | multiply exponents instead of adding; forget to raise the coefficient |
| negative-exponents | Simplify to positive exponents only | fraction of monomials | move the coefficient too; leave a negative exponent |
| adding-polynomials | Sum of two polynomials | polynomial | sign errors; drop a cancelled term wrong |
| subtracting-polynomials | Difference of two polynomials, incl. profit = revenue - cost | polynomial | only negate the first term; add instead of subtract |
| multiplying-polynomials | Monomial×poly, binomial×binomial, binomial×trinomial, table fill-in | polynomial / grid cells | miss middle terms, $(a+b)^2 = a^2 + b^2$, add coefficients instead of multiplying |
| square-roots | Principal / negative / $\pm$ root, area word problems, $\sqrt{(-n)^2}$ | number(s) | give both roots when one is asked; negative answer for a length |
| rational-exponents | Radical ↔ rational exponent, evaluate $a^{p/q}$ | expression / number | flip numerator and denominator; treat $x^{n/1}$ as rational |

## Module 2: Algebraic Expressions and Equations
| Topic | Template | Answer format | Distractors (common mistakes) |
|---|---|---|---|
| translating-words | Single-operation phrase → expression; match phrases to expressions | expression | reversed order for "less than" / "subtracted from"; wrong operation for "of" / "per" |
| commutative-property | Which operations / equations are commutative? | true/false or choice | treating subtraction or division as commutative |
| multi-operation-expressions | Multi-step phrase or word problem (fee + rate, start - rate) → expression | expression | missing parentheses ($2x - 4$ vs $2(x - 4)$); reversed subtraction; numerator/denominator swapped |
| simplifying-rational-exponents | $n^{1/2}$, $n^{1/3}$ with a perfect-power factor; monomial$^{1/k}$; product of two radicals | $a\sqrt[k]{b}$ / radical expression | pull out a non-largest factor; forget the coefficient; wrong index; leave remainder outside |
| solving-rational-exponent-equations | $c \cdot x^{p/q} + d = e$ with nice answers | number or $\pm$ number | forget $\pm$ on even numerator; add $\pm$ on odd numerator; raise to $p/q$ instead of $q/p$; skip isolating |

## Module 3: Functions and Composition
| Topic | Template | Answer format | Distractors (common mistakes) |
|---|---|---|---|
| relations-domain-range | List domain/range of 4-6 ordered pairs | sets | swap domain and range; list repeats; miss a value |
| identifying-functions | Ordered pairs / mapping / equation → function? | yes / no (+ reason) | flag repeated *outputs* as non-functions; miss $y^2$; treat $y^3$ as non-function |
| function-notation | Interpret $f(a) = b$ in context; write a sentence in notation | sentence / $f(a) = b$ | swap input and output; "increased by" readings |
| types-of-functions | Classify an equation as linear / quadratic / rational / radical | family name | $\frac{x^2}{c}$ called rational; radical vs. rational exponent confusion |
| asymptotes | Find vertical and horizontal asymptotes of $\frac{ax^m + \ldots}{bx^n + \ldots}$ | equations of lines | VA from numerator; HA = 0 when degrees are equal; flip leading-coefficient ratio |
| evaluating-functions | $f(\text{number})$, $f(\text{linear expression})$, $f(kx)$ | number / polynomial | $-x^2$ sign error; drop middle term of $(x+a)^2$; forget to apply coefficient to the whole input |
| function-composition | $f(g(a))$ from tables, equations, or mixed | number | evaluate in wrong order; multiply instead of compose |
| decomposing-functions | Given $h$ (and sometimes $f$ or $g$), find the missing function(s) | pair of functions | outer/inner swapped; candidate that doesn't compose back |
| composition-models | Word problem → $g(f(x))$; evaluate at a value; circle/square/sphere/cube with linear radius or side | expression / number (exact or rounded) | wrong composition order; forget to square/cube the rate; decimal approximation when exact asked |

## Module 4: Inverse Functions
| Topic | Template | Answer format | Distractors (common mistakes) |
|---|---|---|---|
| one-to-one-functions | Formula, ordered pairs, or described graph → one-to-one? | Yes / No | even powers / absolute value look fine; repeated outputs missed; restricted domain overlooked |
| inverse-from-table | Table or point of $f$ → $f^{-1}(a)$ or point on $f^{-1}$ | number / point | reading the input row instead of the output row ($f(a)$ instead of $f^{-1}(a)$); keeping the point unswapped |
| inverse-domain-range | Domain and range of $f$ (or graph endpoints) → domain or range of $f^{-1}$ | interval | not swapping; reversed endpoints; open instead of closed |
| verifying-inverses | Linear or cubic pair $f, g$ → inverses? | Yes / No | near-miss inverse with one sign flipped; only checking one direction |
| finding-inverses | Linear, cubic, or $\frac{a}{x - b}$ → $f^{-1}(x)$ | expression | wrong order of undoing; sign errors; reciprocal $\frac{1}{f(x)}$; forgot to swap |
| inverse-applications | Linear model + known output → input | number | plug into $f$ instead of $f^{-1}$; subtract and divide in the wrong order |
| composing-inverses | Points of $g$ + table of $f$ → $(f^{-1} \circ g^{-1})(a)$ | number | use $f$ instead of $f^{-1}$; wrong order; stop after the inner step |
